# Rail-Fence-Cipher-Utility-
This project is an implementation of the Rail Fence Cipher encryption and decryption algorithm using MIPS Assembly language. The program arranges characters of the input text in a zigzag pattern across multiple “rails” based on the given key. The ciphertext is then generated by reading characters row by row then reverse the logic to decrypt.

## Overview
The Rail Fence Cipher is a form of transposition cipher that arranges plaintext characters in a zigzag pattern across multiple "rails" based on a given key.

- Encryption: Characters are written diagonally across rails and then read row by row.
- Decryption: The zigzag pattern is reconstructed to retrieve the original message.

## Features
- Encrypt plaintext using Rail Fence Cipher
- Decrypt ciphertext back to original text
- User-defined key (number of rails)
- Zigzag pattern logic implementation in MIPS Assembly
- Console-based interaction

  ## Technologies Used
- MIPS Assembly Language
- QtSPIM to run the code

  ## How to Run

1. Open QtSPIM
2. Load the `.asm` file
3. Run the program
4. Enter:
   - The text to encrypt/decrypt
   - The number of rails (key)
